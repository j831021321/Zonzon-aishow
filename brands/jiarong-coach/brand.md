# brand.md：佳蓉飲食教練

## 配色：D 蜜桃奶霜（淺色背景＋立體，覆蓋 design-system.md 的 token）

> 2026-11：深色底都覺得太暗（試過深苔綠、A 莓果玫瑰、C 玫瑰奶茶），改成明亮的淺色背景。
> 淺色底和 design-system.md 的預設（深底＋白色強調）相反，下面「淺色版規則」一定要照做。

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#FFF6F1` | 蜜桃奶霜底色（再加兩團白／淡粉的柔光暈） |
| `--ink` | `#4A3135` | 主要文字（深可可） |
| `--r1` | `#E8705F` | 珊瑚：常見錯誤、要小心（當文字用時加深成 `#C94A3A`） |
| `--r2` | `#F0B35A` | 蜂蜜：次要強調（當文字用時加深成 `#A86D14`） |
| `--r3` | `#F49AAE` | 玫瑰粉：**本集主角**（當文字用時加深成 `#D9566E`） |
| `--r4` | `#8FB3A4` | 鼠尾草綠：中性、對照組（當文字用時加深成 `#4C8670`） |
| `--muted` | `#8C7378` | 註腳、出處 |
| `--air` | `#FDE9E2` | 剖面卡底色 |

### 淺色版規則
- 膠囊標籤、問號徽章：深色底白字（`--ink` 或 `--r1`），不要白底（白底在淺色背景上看不到）。
- 卡片：白色漸層（`#FFFFFF → #FFF1EC`）＋柔和陰影（`0 34px 60px rgba(150,70,70,.16)`）。
- 主角光圈：`--r3` 外框＋粉色光暈，不用白框。
- 淺色文字在淺色底上對比不夠：彩色字一律用上表「當文字用時」的加深色。
- 半夜場景的暗化色：`#2B2442`（35%）。

### 立體感（精緻版）
- 器官用放射漸層做光影（亮面在左上），加一塊半透明白色高光、下方柔和投影。
- 肌肉纖維用直向漸層做成圓柱。
- 小東西（蛋白質）用等角立體方塊（上、左、右三面三種深淺）。
- 長條、關鍵字膠囊：下方 7～10px 的深一階「厚度」陰影，像實體按鈕。
- 餐盤用 `rotateX(48deg)` 傾斜成盤子。
- 進場動作：卡片 3D 翻入（`rotationX`／`rotationY` 30～55° → 0，`transformPerspective` 1200～1600），開場卡片微微傾斜並上下漂浮。

做 composition 時，把上表的值寫進 `:root`，其餘照 design-system.md。

## 畫面偏好

- 多用**餐盤、一天的時間軸**：「早餐 → 午餐 → 晚餐」同一個餐盤換內容，蛋白質、蔬菜、澱粉用顏色分區。
- 剖面以**胃、腸道、肌肉、血糖曲線**為主；「吃對 vs 吃錯」用同一個剖面換顏色（`--r1` → `--r4`）；半夜場景的暗化色用 `#140C12`。
- 外食場景很適合：便當、超商、聚餐、出國的餐點怎麼挑。
- 畫面溫柔、生活感，像姊妹在旁邊教你。
- **不畫產品包裝、不放公司 logo、不放身材前後對比、不放體重計數字。**
