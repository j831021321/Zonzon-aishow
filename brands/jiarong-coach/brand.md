# brand.md：佳蓉飲食教練

## 配色：C 玫瑰奶茶（覆蓋 design-system.md 的 token）

> 2026-11 從「深苔綠＋奶茶杏」改成玫瑰奶茶：女生客人比較喜歡（試過 A 莓果玫瑰，覺得太老氣）。

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#33282A` | 深可可底色 |
| `--ink` | `#FAF0EA` | 主要文字 |
| `--r1` | `#E07A6F` | 珊瑚紅：常見錯誤、要小心的地方 |
| `--r2` | `#D9A86C` | 焦糖：次要強調 |
| `--r3` | `#F2C4B8` | 蜜桃粉：**本集主角** |
| `--r4` | `#A3968F` | 灰奶茶：中性、對照組 |
| `--muted` | `#CDBDB6` | 註腳、出處 |
| `--hi` | `#FFFFFF` | 光圈、膠囊標籤 |
| `--air` | `#423437` | 剖面卡底色（比底色亮一點） |

做 composition 時，把上表的值寫進 `:root`，其餘照 design-system.md。

## 畫面偏好

- 多用**餐盤、一天的時間軸**：「早餐 → 午餐 → 晚餐」同一個餐盤換內容，蛋白質、蔬菜、澱粉用顏色分區。
- 剖面以**胃、腸道、肌肉、血糖曲線**為主；「吃對 vs 吃錯」用同一個剖面換顏色（`--r1` → `--r4`）；半夜場景的暗化色用 `#140C12`。
- 外食場景很適合：便當、超商、聚餐、出國的餐點怎麼挑。
- 畫面溫柔、生活感，像姊妹在旁邊教你。
- **不畫產品包裝、不放公司 logo、不放身材前後對比、不放體重計數字。**
